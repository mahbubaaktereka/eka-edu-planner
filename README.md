Smart Study Planner
A modern study planning application built with React and Tailwind CSS.

Features
Add study tasks
Complete and undo tasks
Delete tasks
Subject categorization
Due dates
Search tasks
Filter tasks (All, Completed, Pending)
Dark mode
Local storage persistence
Dashboard statistics
